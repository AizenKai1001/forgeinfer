## Forge Studio and ForgeInfer v0.1.5 (pre-release)

The speed governor of v0.1.4 keeps what it measured from one request to the next, and the long-context numbers of the RTX 4060 are in.

**The governor remembers.** v0.1.4 measured the ways of getting the next tokens (a plain step, the head's chain, drafts looked up in the text) afresh in every request from 6,000 positions on; in a 100-token answer that was about 10 percent of the time. The governor now lives in the engine worker and starts every request from what the earlier ones measured (it counts for no more than its minimum number of measurements, so the new text decides quickly; a chain that was given up is tried again once the head is usable, which it is after a new chat has been read). Qwen3.5-4B on the RTX 2060 SUPER, 8-bit keys and 4-bit values, four requests of one server at 4,096 / 16,384 / 32,768 / 65,536 positions: asked to copy a passage, x2.32 / x1.98 / x1.58 / x1.25 of plain decoding with the governor against x2.32 / x1.93 / x1.55 / x1.22 without it (v0.1.4: x2.29 / - / x1.38 / x1.11 in its first request); asked for a story x1.27 / x0.96 / x0.95 / x0.95 against x1.27 / x0.98 / x0.84 / x0.76 without the governor.

**The RTX 4060** (Windows 11, the release build, 1.5 GB of the 8 GB in use by the desktop), Qwen3.5-4B Q4_K_M ([PERFORMANCE.md](https://github.com/AizenKai1001/forgeinfer/blob/main/docs/PERFORMANCE.md#long-contexts)):
- `--ctx auto` opens 88,064 tokens with the 16-bit cache, 126,976 with `int8`, **151,552 with `k8v4`** and 187,392 with `int4`; a planted fact in a prompt of **141,948 tokens** was found, the prompt read in 90 seconds (1,573 tokens/s on average over the depth; the 2060 SUPER needed 469 seconds for 187,000).
- The 8-bit keys / 4-bit values cache decodes **faster than the 16-bit cache** from 32,768 positions on: 64.7 against 59.5 tokens/s at 32,768 and 53.1 against 48.8 at 65,536 (it reads 40 percent of the bytes from the card's 272 GB/s); the shared-head attention of v0.1.3 gives +19 and +26 percent with that cache, and nothing with the 16-bit cache (the Ada card's 24 MB of L2 absorb the repeated loads).
- The draft head's chain, with the governor: a story x1.45 / x1.13 / x1.00 / x0.93 of plain decoding at 4,096 / 16,384 / 32,768 / 65,536 positions, a copy x2.99 / x1.89 / x1.42 (4,096 / 32,768 / 65,536).

Everything else is as in [v0.1.4](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.4).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
