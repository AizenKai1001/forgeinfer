## Forge Studio and ForgeInfer v0.1.10 (pre-release)

**EPUB books and web pages in chat with documents.** Drop an `.epub` or a saved `.html` page on Forge Studio's window like a PDF: an EPUB gives its chapters in the order of the book's spine (or in the order of their names when the book has no readable spine), a web page its text without scripts, styles and comments, with a line break where a paragraph, heading, list item or table row ends and the entities (`&amp;`, `&rsquo;`, `&nbsp;` ...) decoded. A format that is not read yet (`.doc`, `.xls`, `.xlsx`, `.ppt`, `.odt`, `.rtf`) now says what to do (save it as a PDF or a `.docx`) instead of "not a text file".

**Discover starts with suggestions.** Before anything has been searched, the Discover screen offers a few good first downloads with their exact repository and file (names and sizes checked against Hugging Face): Qwen3.5 4B, 9B and 0.8B, Qwen3 4B Instruct 2507, and nomic-embed-text v1.5 (the embedding model of chat with documents), each with a "fits in video memory" badge and a Download button, or "already in My models".

**Chat with documents, details.** A file that leaves the chat (the message that carried it was deleted) is no longer searched; vectors of any length from a server give cosines (they are scaled to length one when they are stored); the README and STUDIO.md describe the feature with a screenshot of a PDF chat.

Everything else is as in [v0.1.9](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.9).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
