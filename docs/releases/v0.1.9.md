## Forge Studio and ForgeInfer v0.1.9 (pre-release)

Chat with documents, finished off.

**Page numbers.** A PDF is read page by page, a passage never crosses a page, and the passage the model reads says where it comes from: "Citation 1 (from paper.pdf, page 9)". The list under your question (click "3 passages of your files read by the model") shows `paper.pdf · page 9 · score 0.71`.

**Questions about the whole document.** Searching by meaning cannot find "the abstract" or "what is this about": a question that asks for a summary, an overview, an abstract, an introduction or the gist now gets the opening passage of each file (two files at most) in front of its best matches. With a 0.8B model and a 4,096-token context, "What does the abstract say?" on an 8-page paper (Bellard's NNCP report) was answered from page 1 instead of from a table on page 9.

**A strip names the files.** A chat that searches its files shows "Searching paper.pdf (18 passages): the model reads the best passages for each question" under the model bar, and the tip under the input box says that PDF, Word, PowerPoint, text and code files can be dropped on the window.

Everything else is as in [v0.1.8](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.8).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
