## Forge Studio and ForgeInfer v0.1.7 (pre-release)

**Chat with documents.** Drop a text or code file on Forge Studio's window and ask about it, however long it is. A file that fits the context goes in whole, as before. A file that does not (more than 70 percent of what is left of the context) is searched: it is cut into overlapping passages, the embedding model that v0.1.6 added turns each passage into a vector, and for every question the model gets only the best three passages (cosine above 0.6) in front of the question, with the name of the file they come from. Under the question a line says how many passages the model read, and clicking it shows them with their scores; the passages of earlier questions are dropped from what the model reads when a newer question is asked, so a conversation about a 500 KB file fits in a 4,096-token context. Reading a 497 KB file (338 passages, 114,000 tokens) takes 3.0 s on an RTX 4060 and 122 s on the CPU; a question then costs one embedding (a few milliseconds). Tried with a 0.8B model: a fact buried in the middle of 511 KB of ledger text was found and answered, a follow-up about it too, and a question the file does not answer matched no passage and was answered from the model's own knowledge.

The embedding model runs inside the chat engine process (`forge serve CHAT.gguf --embedding-model nomic.gguf`, on the GPU when there is room for it, else on the CPU) and loads together with the chat model. **Settings > Documents** shows which embedding model is in use (an embedding model of My models, else the one LM Studio ships when it is installed), downloads nomic-embed-text-v1.5 (84 MB) when there is none, and sets the number of passages and the minimum score. Details: [STUDIO.md](https://github.com/AizenKai1001/forgeinfer/blob/main/docs/STUDIO.md#chat-with-documents).

**Engine.** `--vram-reserve` now also applies to the automatic context (`--ctx auto` left 256 MB free whatever the flag said); with an embedding model on the GPU next to a chat model the engine adds 450 MB to it so that the embedding model finds room after an automatic context has taken what it plans for.

Everything else is as in [v0.1.6](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.6).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
