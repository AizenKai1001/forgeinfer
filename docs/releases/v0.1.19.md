## Forge Studio and ForgeInfer v0.1.19 (pre-release)

**More embedding models: the BERT family.** `forge serve` and Forge Studio now run **bge**, **all-MiniLM**, **e5** and **gte** models next to nomic-embed-text (checked: bge-small-en-v1.5, bge-base-en-v1.5, all-MiniLM-L6-v2, e5-small-v2 and gte-small; their other sizes are the same code with other matrix sizes), on the CPU and on the GPU: learned position embeddings, a bias on every matrix, the exact GELU, and the `[CLS]` or mean pooling that the file asks for. They are checked against Hugging Face `transformers` itself, not against another port: the token ids equal the reference on every text, the vectors of the f32 files have cosine 0.9999999 on the CPU and 0.999999 on the GPU (the Q8_0 files 0.999, their own rounding), and the `/v1/embeddings` route passes the same HTTP checks as before (a batch of 23, base64, `dimensions`, the error replies) on both. A small model is a good deal on a small card: bge-small embeds 167,000 tokens/s on an RTX 2060 SUPER (nomic-embed-text: 70,000) and 2,040 tokens/s on 8 CPU threads (790), in 37 MB. A BERT-shaped model with a SentencePiece vocabulary (bge-m3, multilingual-e5) is refused with a message that says why. A cased vocabulary has not been tried. Numbers, the tests and the models: [EMBEDDINGS.md](EMBEDDINGS.md).

**Studio picks the minimum score and the task prefixes that suit the model.** Models spread the cosine very differently: related passages score 0.63 to 0.9 with nomic-embed-text and 0.23 to 0.48 with MiniLM, while e5 and gte put every pair of texts between 0.7 and 0.9. One fixed minimum (0.6) was right for nomic-embed-text only. Settings > Documents > **Minimum score** is now automatic by default and uses the figure measured for the model in use (nomic-embed-text 0.60, bge 0.58, MiniLM 0.20, e5 0.82, gte 0.78; the table and how it was measured are in EMBEDDINGS.md, `tools/embed_calibrate.py` repeats it for another model); a number you had typed before stays yours. e5 gets its `query: ` and `passage: ` prefixes, the embedding playground's sample lines carry the prefixes of the loaded model, and **Discover** lists bge-small-en-v1.5 (37 MB) next to nomic-embed-text.

Everything else is as in [v0.1.18](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.18).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
