## Forge Studio and ForgeInfer v0.1.17 (pre-release)

**Excel numbers are shown as the cell shows them.** A cell formatted as a percentage came out as its stored number (0.256 for "25.6%"), a price as 1234.5 for "$1,234.50", a code with leading zeros as 5 for "00005". Studio now applies the number format of the cell's style: digit placeholders (`0`, `#`, `?`), thousands separators, percent, scientific notation, text in quotes, currency blocks such as `[$EUR-407]`, and the negative and zero sections of a code (`($1,234.50)`, `"zero"`). Fractions, conditions, scaling commas and the General and Text formats are left as stored.

Checked against Excel itself: a workbook with 23 values in 23 different formats was saved by Excel as `.xlsx` and as CSV (the CSV holds what Excel displays), and Studio's reading of the `.xlsx` was compared cell by cell: 22 equal, and the 23rd differs only by a trailing space that the row trimming removes. Excel rounds halves away from zero (1234.5 in format `0` is 1235) where most programming languages round them to even, which the formatter takes into account.

Also: a web address or an e-mail address that a PDF cuts over two lines at a hyphen keeps its hyphen (`.../hybrid-cloud` was read as `hybridcloud`).

Everything else is as in [v0.1.16](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.16).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
