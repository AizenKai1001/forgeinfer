## Forge Studio and ForgeInfer v0.1.11 (pre-release)

**More files to chat with: Excel, OpenDocument and RTF.** Drop an `.xlsx` workbook on Forge Studio's window like a PDF: every sheet comes under a "Sheet: name" line with one line per row and the cells separated by tabs (an empty cell keeps its place, so the columns stay in line), dates show as dates, and a formula shows the value Excel last computed. OpenDocument files (`.odt` text, `.ods` spreadsheet, `.odp` presentation: the formats of LibreOffice) and `.rtf` files (what WordPad saves) are read too; comments and the records of tracked changes are left out. The old binary formats `.doc`, `.xls` and `.ppt` still need a "save as" first, and the message now names the format to save as.

What was tried: three spreadsheets written by Excel (a Gantt chart with a few dozen rows), real PDFs, and files built by the tests for every format. No real LibreOffice or WordPad files were at hand, so OpenDocument and RTF are the least proven of the readers: if one gives wrong text, the file is the best bug report.

Everything else is as in [v0.1.10](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.10).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
