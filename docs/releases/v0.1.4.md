## Forge Studio and ForgeInfer v0.1.4 (pre-release)

Speculative decoding no longer slows a long chat down. Measured on an RTX 2060 SUPER (8 GB) with Qwen3.5-4B Q4_K_M and its prediction head; the numbers on an RTX 4060 were not remeasured for this release.

**The problem.** The head drafts a chain of tokens and the main model verifies all of them in one sweep over several rows. Every row of a sweep reads the whole KV cache, so the sweep gets dearer with the context: after a 64,000-token prompt a cycle costs about three plain steps and gives about two tokens. Decode speed after a long prompt, tokens/s (8-bit keys, 4-bit values, the chat of Studio's "Longest possible"; a story requested, greedy):

| context | plain decoding | the head's chain (v0.1.3) | v0.1.4 |
|---|---|---|---|
| 4,096 | 98.6 | 124.9 | 124.6 |
| 16,384 | 97.5 | 95.3 | 97.8 |
| 32,768 | 82.3 | 68.8 | 78.8 |
| 65,536 | 62.8 | 47.8 | 59.4 |

**A speed governor.** From 6,000 positions on, the decoding loop times every iteration and keeps, for each way of taking the next tokens (a plain step, a cycle of the head's chain, a cycle of drafts looked up in the text), the tokens per millisecond it gave; it takes the best one and tries the others now and then (the closer an arm is to the best, the more often), so the speed follows the context and the text: a repetitive answer still gets its drafts at a long context, a story does not. A chain that stays far behind (below 78 percent of the plain rate after six measurements) is given up for the rest of the request and the head's cache is no longer kept in step. Below 6,000 positions nothing changes (the loop behaves exactly as before), and every drafted token is still verified by the main model, so what is sampled is what plain decoding would sample. `FORGE_GOVERN=0` turns the governor off, `FORGE_GOVERN_FROM=N` sets the position from which it decides; `FORGE_SPEC_STATS=1` prints how many iterations each way took.

Where it is measured and why it stops short of plain decoding at the greatest depth: [PERFORMANCE.md](https://github.com/AizenKai1001/forgeinfer/blob/main/docs/PERFORMANCE.md#speculation-at-a-long-context).

Everything else is as in [v0.1.3](https://github.com/AizenKai1001/forgeinfer/releases/tag/v0.1.3).

Unsigned binaries. Studio has been run on Windows 11 with an RTX 4060 and on Ubuntu 24.04 (X11) with an RTX 2060 SUPER; the macOS build is compiled and unit-tested by CI but nobody has run its window yet.
