# tools/ index

Every script in `tools/` and `tools/sft_data/`, grouped by purpose. The one-line descriptions are the first sentence of each script's own docstring or header comment. `(old)` marks scripts that look obsolete or superseded; nothing has been moved or deleted.

Tests: `python -m unittest discover -s tools/tests` (standard library only).
